# mPredictor

Static page that estimates the chance of a Tamil Nadu government DGNM seat from a community rank, based on 2025 counselling results.

`data/dgnm.json` holds aggregates only: seat counts and the last community rank allotted per college, community and round. It contains no names or application numbers. It is generated from a separate private source with `mpredictor_build_data.py`.
